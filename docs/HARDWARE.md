# 本体与工具链

首批目标见 [机器可读清单](../toolchain/hardware_targets.json)：幻尔、飞特、DYNAMIXEL、优必选、达妙、灵足、宇树，以及直流／无刷驱动板。多数电机适配仍为 planned；飞特已提供协议诊断和供可信 Host 集成的 STS3215 受限位置控制原语，见 [FEETECH](FEETECH.md)。终端真机运动与硬件验收尚未开放。基础串口接收已有独立实现，见下文。

按型号＋固件＋协议适配，不按品牌猜测反馈。位置、电流、厂商估算负载和实测力矩分别声明，缺失不补零。角度以 rad、速度以 rad/s、电流以 A、力矩以 N·m 表达，并标注电机轴／输出轴与信号来源。

无摄像头建议接入，但本体感觉任务不依赖相机。自主探索需已确认安装、标定、工作区、限制与本地停止能力；未知环境不能凭电流恢复完整地图。外部对象任务需有足够外部证据。

一脑多本体共享任务／技能，隔离 body_id、标定、动作会话、执行所有权和停止域。发现设备不自动使能，拔插／本体变更使旧动作失效。当前模拟实现仅覆盖部分契约，不能直接用于上述真机保护。

`validate_trajectory` 只检查维度、数值、关节范围、时间递增和相邻采样平均速度，不检查加速度、曲线中间极值、碰撞或动力学，不可作为真机安全认证。

型号反馈事实及厂商来源见 [原始调研第 12 节](../../projects/reports/06_loopmaster_core_landscape_and_design.md#12-首批执行器适配与无视觉本体探索)。

## 基础串口接收

`devices`/`/devices` 读取/dev及sysfs，返回真实别名映射、内核驱动、USB VID/PID和物理USB路径，不打开设备。多个视频节点按usb.device_path归并，不能按节点数报告摄像头数量。接口身份不证明电机型号。

模型工具 `open_serial(port, baud)`、`read_serial(max_bytes=256, timeout_ms=200)`、`serial_status()`、`close_serial()` 由 [serial_port.py](../toolchain/serial_port.py) 实现，Linux标准库，无额外依赖。采用8N1；波特率支持9600、19200、38400、57600、115200、230400、460800、921600。仅打开已发现的USB串口节点，独占会话；每次最多读取4096字节、等待1000ms，返回hex。不提供写入或未知协议扫描，不将接收字节解释成电机型号。打开串口仍可能触发驱动的DTR/RTS变化或设备复位，不能称为完全无副作用。

端口和波特率由用户明确给出；plan阻止打开/读取，sim允许按现有权限规则使用接收工具。关闭和状态查询可随时进行；定时任务禁止打开/读取/关闭串口。会话退出关闭串口，断线不自动重连。无需启用真机运动模式，不删除模拟本体保护。

2026-09-05 本机只读核对：`/dev/serial/by-id/usb-1a86_USB_Single_Serial_5A7C120712-if00` → `/dev/ttyACM0`，`cdc_acm`，USB `1a86:55d3`，产品`USB Single Serial`；电机型号未知。`video0`和`video1`同属`04f2:b760`、HP Wide Vision HD Camera。设备名可能随拔插改变，每次重新枚举；未打开这些真实设备。

电流/力矩计算、PID离线试验与故障排查工具已接入；具体格式、资料和真机待验收边界见[机器人工程Agent](ROBOTICS_AGENT.md)。

2026-09-05 设备枚举：`devices` 只读 `/dev` 和 `/sys`，现包含 USB 总线设备（含集线器）、串口/摄像头节点与 input event 名称。自然语言“可以检测我的电脑连接上了什么吗？”直接通过现有权限门禁执行枚举，不等待模型承诺；否定/教程提问不自动执行。显示实际设备名称及节点，长列表部分省略并保留 /details 完整结果；不读取 USB serial，不打开设备或发送字节。输入节点和 USB 项数不等同独立外设数，内置设备与集线器也可能出现。Windows/macOS 已补 pySerial 串口枚举与接收分支（替身测试，原生实物待验证）；仅枚举串口与关联 USB 描述信息，缺依赖时明确报告未完成。


驱动接入时先用robot_toolchains核对SDK安装状态，已知型号用robot_docs/web_search查官方SDK与协议；未知型号询问电机/驱动板型号和连接方式，不把USB接口身份当电机型号。官方库入口与当前缺口见[接入记录](../../projects/reports/14_motor_driver_integration_gap.md)。用户授权、库安装、驱动接入、设备配置分别记录。


2026-09-05 “读取我的机械臂”直接触发本机设备枚举，不能依据 MuJoCo 无模型判断无硬件。记录 `robot_assessment`：串口候选、未知型号/电机数/轴数、未确认的控制就绪状态。明确仿真请求不触发硬件查询。Windows COM、macOS `/dev/cu.*` 通过 pySerial 枚举，只接受枚举出的本地端口，接收限制 4096 字节/1000ms；不提供发送接口。端口打开仍可能受驱动 DTR/RTS 行为影响，不自动猜测波特率并打开未知设备。

读取原始字节不等于识别型号。下一步需控制板型号/固件/协议/波特率，按官方身份与状态查询取得电机 ID，再与关节映射核对轴数（夹爪等可能另计）；接入对应写入驱动、标定/限位/停止回执后才能进行实际控制测试。当前没有实现通用电机自动探测或真机运动驱动。资料依据：[pySerial 枚举](https://pyserial.readthedocs.io/en/latest/tools.html)、[端口 API](https://pyserial.readthedocs.io/en/latest/pyserial_api.html)。
