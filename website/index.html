From intent to evidence.

01 / INTERACT

Your terminal, your models.

Configure an API URL and key. Choose your provider, switch models, and keep user instructions in ~/.loop.

02 / EXPERIMENT

Start in simulation.

MuJoCo scenes, trajectory tools, optional Mink kinematics and policy-service orchestration. Keep heavy dependencies optional.

03 / REVIEW

Keep the feedback.

Episodes and reviews make results inspectable. A tool returning success is not proof that the task succeeded.

DEVELOPMENT PREVIEW

Hardware motion is disabled. Hardware access remains permission-gated. Automatic model training and general-purpose robot manipulation are not shipped capabilities.

ONE COMMAND. THEN TYPE LOOP.

A workspace on your terms.

Linux/macOS: paste one command into your terminal to download and install Loop ROS. Windows: download and run the PowerShell installer. Python 3.8+ starts the installer; uv creates an isolated Python 3.12 environment automatically.

curl -fsSL https://loopmaster.box2ai.com/LoopROS/install.sh | sh

Linux hosted installation tested with Python 3.8 bootstrapping a uv Python 3.12 runtime.

After installation: open a new terminal and run loop or loop ros. On Linux/macOS, add ~/.local/bin to PATH if prompted.

Version 0.0.1 is available over verified HTTPS. After installation, use loop update to get newer releases.
