A SMALL CORE. A COMPLETE FEEDBACK PATH.

From intent to evidence.

Master coordinates the work. Tools execute within permissions. Review records what actually happened.

01 / INTERACT

Your terminal, your models.

Configure an API URL and key. Use Qwen by default, switch providers, and keep user instructions in ~/.loop.

02 / EXPERIMENT

Start in simulation.

MuJoCo scenes, trajectory tools, optional Mink kinematics and policy-service orchestration. Keep heavy dependencies optional.

03 / REVIEW

Keep the feedback.

Episodes and reviews make results inspectable. A tool returning success is not proof that the task succeeded.

DEVELOPMENT PREVIEW

Hardware motion is disabled. Linux serial support is receive-only. Automatic model training and general-purpose robot manipulation are not shipped capabilities.

ONE COMMAND. THEN TYPE LOOP.

A workspace on your terms.

Linux/macOS: paste one command into your terminal to download and install Loop ROS. Windows: run the PowerShell installer from the source folder. A compatible Python 3.10+ with pip and venv is required.

curl -fsSL https://8.134.90.171/LoopROS/install.sh | sh

Ubuntu 20.04 tested with private Python 3.13. Ubuntu 16.04/18.04 need a compatible private Python or SSH. 22.04/24.04/25.04 are not individually verified.

After installation: open a new terminal and run loop or loop ros. On Linux/macOS, add ~/.local/bin to PATH if prompted.
