打开本地仿真工作台

在安装了仿真依赖的 Loop ROS 环境运行：

loop web

源码环境：

.venv/bin/python -m terminal.web_workbench

然后访问 http://127.0.0.1:8768/workbench.html。官网静态预览不会连接或操作本机。

Isaac 需先启动其工具桥。工作台实例归本地网页服务所有，与已有终端实例和 GUI 分开。
